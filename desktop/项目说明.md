# Suo 桌面端

React + TypeScript + Vite 构建工作台，Tauri 2 提供 macOS 窗口与本地文件桥接。现有 Suo 内置模型通信模块负责对话，Excalidraw、PDF.js 和 Markdown 阅读组件按需加载。

## 开发与打包

双击 `start.command` 开发，或运行 `npm run dev` 查看浏览器版本。`npm run bundle` 生成 `src-tauri/target/release/bundle/macos/Suo.app`；打包脚本使用项目的 `.cargo-cache`，包含 Node 与引擎运行时，用户使用 App 时不需要另装 Node 或 Rust。源码开发仍需项目依赖和 Rust 工具链。之后运行 `npm run dmg`，把这个 App 做成 `src-tauri/target/release/bundle/dmg/Suo_<版本>_<芯片>.dmg` 安装包（只用系统自带的 hdiutil，不会重新编译）。

后台服务（Node）意外退出时，桌面外壳会在 1、2、4… 秒后自动重启它，10 分钟内最多 5 次，恢复后界面自动重新保存；超过次数会提示重新打开 Suo。导入文件和清空回收站最长等待 10 分钟，其他操作 30 秒。后台输出和启停记录写入数据目录的 `logs/bridge.log`（App 在 `Application Support/local.suo.desktop/logs/`，开发版在 `data/logs/`），超过 1 MB 轮换一次。

本机包使用临时签名。公开分发前需要 Developer ID 签名、公证与目标机器验证；打包不会自动公开发布。

## 模型连接与保存

设置分为外观、模型、操作与布局、关于；支持主题、背景、动态效果和发送快捷键。模型支持 OpenAI 兼容、OpenAI Responses、Anthropic，以及桌面端导入直接 API Key 配置的 models.json。添加模型保留其他连接与同接口已有模型。Tailscale Funnel 接口可选择公网通道，保留 TLS 主机名验证，不修改系统 DNS。开发版未添加连接时读取 Suo 的 `state/agent/models.json`，不修改原文件；App 在本机数据区管理自己的连接。配置使用私有文件权限和版本式保存，不进入会话、前端资源和安装包。

默认显示 Best（自动选择已保存默认模型，否则使用首个有效连接），也可手动指定模型后发送真实请求，流式显示回复，支持停止与明确报错；不会自动重试或用演示回答替代失败。回复失败时先说明原因，模型更换与连接配置仍从输入框和设置进入；不显示技术详情，历史错误只呈现中文原因。用户消息与 AI 回复默认只显示在右侧对话栏，不自动生成想法便签或回复卡片；双方消息均可点击“放到画布”，生成可编辑文档卡片，重复点击会定位已有卡片。发送时上传的附件仍保留为资料卡片。对话携带有效历史，超出预算时保留近期内容并提取早期原文摘记，界面显示压缩提示，完整聊天记录仍保存。文本、Markdown、HTML 与 Mac 的 Word 正文可作为引用；PDF 在本地提取最多 200 页、2 万字，扫描 PDF 需另行提供文字。图片缩至最长边 1536 像素并作为视觉内容发送，需在模型记录启用图片分析，接口本身也必须支持；最多 4 张、压缩后单张 2 MB、合计 6 MB。供分析的原文件最多 20 MB；音视频与其他二进制格式暂不支持内容分析，发送前明确报错。对话以 Agent 方式运行：模型可以调用工具，最多 16 轮，单次任务最长 10 分钟。工具有：查看画布（board_read）、放到画布（board_write，卡片可分组、连线）、调整画布（board_edit，修改、排列、分组、连线；只能删除 Suo 创建的卡片）、撰写文档（document_write，可按章节替换）、读取资料（read_material，长资料分段）、搜索资料（search_materials，搜索当前画布的资料和卡片）、读取网页（web_fetch，只能打开公开网址，跳转后同样检查）、使用技能（use_skill，只读技能目录）。画布、文档和资料工具由界面执行，与用户操作走同一条保存与撤销路径；用户正在编辑的卡片不会被修改。工具调用以进度条目显示在回复上方；只有用户明确要求操作画布或已有文档时才使用写入工具；技能结果同样遵守这一规则。技能面板支持新建、导入 SKILL.md 或技能文件夹，并编辑已添加的技能；开发版保存到 Suo 根目录的 `skills/<名称>/SKILL.md`，App 自定义技能保存到本机数据区 `skills/`，与只读内置技能合并展示。front matter 需要 name 和 description，可选 display_name；文件夹可带文本参考资料，每个文件最多 400 KiB、最多 64 个参考文件、总计 2 MiB，不运行随附脚本。内置技能只读，自定义技能用版本校验防止并发覆盖；Agent 的 use_skill 读取同一技能库。自定义模板保存到本机数据区 `templates/`，可编辑并插入为普通文档卡片。联网搜索（web_search）不需要 API Key：桌面 App 用系统自带的网页内核（Mac 上为 WebKit）在隐藏窗口中打开搜索引擎并读取前 10 条结果，窗口无痕、不带登录和 Cookie，只读、拒绝下载和弹窗、不能打开本机或局域网地址，15 秒超时后关闭。Agent 默认提供联网搜索工具，需要最新信息、市场或竞品资料时按需使用；搜索引擎自动选择，中文搜索词用百度（过滤推广、图片和智能分身卡片），英文用必应。直接抓取时正文过少的网页（需要脚本渲染）会改用同样的隐藏窗口读取。搜索引擎要求人工验证时如实报错。浏览器开发版没有隐藏窗口，联网搜索只能在 App 中使用。

开发网页的模型请求通过仅监听本机的服务连接引擎；来源、请求令牌与方法白名单均受检查。浏览器会话仍保存在原站点，新导入文件正文保存在该站点的 IndexedDB，切换会话与刷新后可重新读取；旧预览中未保存正文的资料需重新导入，不自动迁移。打包 App 的会话、文件和连接在 macOS 的 `Application Support/local.suo.desktop` 中；开发版使用 `data/`。关闭与切换会话时提交编辑并停止当前回复。

## 工作台

首页输入框固定；进入工作台后默认靠底部，仍可移动和拉伸。对话、输入框与工具栏固定在内容上层，不显示置顶按钮；卡片、阅读框与草图编辑框可置顶。图片没有标题条，按原比例缩放。双击附件放大阅读，点击阅读框外或 Esc 收起。浮动面板空白处直接拖动，四边和四角拉伸，不显示拖动握柄或角标；拖动中按帧更新，结束后保存。立项等模板作为可自由修改的文档，双击正文原位编辑；技能入口按卡片排列，顶部独立新会话按钮无需展开列表。设置切换标签保持窗口尺寸。便签和文档原位编辑；草图双击放大后保持只读，点击编辑草图继续绘制。草图文件菜单、样式与颜色面板可点击外部空白收起，窗口外点击会保存后收起编辑框。卡片连线表达关系并随会话保存，不自动执行或扩大模型引用范围。

文件上限 200 MB。PDF 连续滚动并按需渲染；CSV 保留引号与前导零；HTML 保留内嵌布局与样式，隔离脚本和外部资源；图片、音视频支持本地分段读取。Mac 的 Word 阅读提取正文，不保证原排版；扫描 PDF 暂不提供 OCR。

画布框选与卡片相交即可选中，无需完整包住；Ctrl+A 或 Cmd+A 全选卡片；正文编辑、附件阅读和绘图保留对应区域的全选。首页与界面控件不产生整页文字选区。首页隐藏新建图标，工作台使用独立的方框铅笔图标。会话列表可重命名、置顶或删除；删除进入应用回收站，可恢复，会话正文和附件不物理删除。手动名称不会被首次发送的消息覆盖。

设置模型页可打开已保存记录修改；修改模型 ID 替换原记录，不丢同接口的其他模型。未通过检查的配置保存为私有草稿，切换页面或重启后仍可继续修改；草稿不参与对话模型选择，Key 不回传给界面。API Key 仅在接口类型及地址均未改变时留空保留已存密钥；换地址或类型必须重新输入，原密钥不发往新地址。输入框不标记为创建新密码。每次配置只写一份提交记录，连接保留最近 3 个有效版本，会话保留最近 30 个有效版本；旧版本移入系统废纸篓，不自动清空系统废纸篓。多个桌面进程使用文件锁，多个浏览器标签页使用工作区锁。

回收站可清空，操作前列出会话并再次确认。桌面版把会话和未共享附件移入系统废纸篓；浏览器版永久移除本地记录。其他会话及历史引用的共享附件继续保留。

验收后更新约定的唯一 App 交付位置，不再另建时间戳目录复制整份 App。

## 验证

`npm test` 只写入 `preview/test-runs/run-UUID` 的隔离目录，不写用户 `data`。无隔离环境直接执行写文件测试会被拒绝。测试结束记录归属与结果，收尾按确认清单整体移入废纸篓。

测试包含版本保存、文件读取、画布、模型流式通信、取消、报错和本机接口边界。模型通信自动测试使用本机假接口，不消耗外部额度。`npm run build` 检查类型与前端构建。

卡片分类：便签、文档、文件、草图及分组支持手动设置背景颜色和标签。单选一个块后，使用左侧工具栏的“颜色与标签”图标设置；无选中或多选时不执行修改。默认颜色随黑白主题，另有预设颜色和自定义十六进制颜色。标签最多 8 个，每个最多 32 字符，自动去空格和重复。设置保存到卡片数据，与会话一同保存，支持撤销/重做；编辑正文、置顶和分组不会丢失分类。媒体内容自身不变，颜色通过边框与标签区域显示。

消息内容与错误提示不使用气泡或边框；普通消息与错误消息统一使用复制、放到画布两枚图标，放在每条消息末尾右侧，在消息悬停或键盘聚焦时显示，触屏保留可点入口；对话栏不再放置导入资料与继续整理快捷按钮。

新建菜单、输入工具与斜杠命令不再提供立项框架快捷入口；技能库中的现有技能、模板及已有文档保留。

错误消息的复制与手动贴卡使用当前可见的中文内容；发生错误前的部分回复一并保留，原始技术报错不进入复制内容或卡片。已停止的回复保留原重试入口。
